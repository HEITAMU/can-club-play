# 罐头远征队 · 微信小游戏测试工程

AppID：`wx43da24c6ac1e5a12`。当前按用户提供的测试号配置，不代表已经上传微信、完成审核或正式发布。

## 导入试玩

下载 `can-club-wechat-v0.21.0.zip`，解压后在微信开发者工具中选择“小游戏 → 导入项目”，项目目录选解压出的目录（其中直接包含 `game.js`、`game.json`、`project.config.json`），使用有此 AppID 开发权限的微信登录。从源码自行构建时，项目目录是 `dist/wechat`。若工具提示该测试号无权限或不属于小游戏，请先在工具中确认账号类型和开发者身份，不要修改为其他人的 AppID。

工程使用原生 Canvas，不包含 web-view，不依赖 GitHub Pages，也没有业务服务器域名。正式预览二维码必须由微信开发者工具的“预览”生成。这里提供的是可导入测试工程，尚未经过微信开发者工具及真机验证。

## 从网页继续进度

网页“设置 → 复制存档”，然后在微信游戏“设置 → 导入网页存档”手动粘贴。微信进度与网页进度独立保存；导入前有覆盖确认。微信本地存档保留上一份有效备份。切到后台立即保存，返回时计算按鱼箱等级上限结算鱼摊收入；战斗不会在后台快进。

## 开发构建

在仓库根目录执行：

```sh
npm install --prefix wechat
npm run build --prefix wechat
npm test --prefix wechat
npm run review --prefix wechat
```

输出 `dist/wechat`。换正式 AppID 时使用 `WECHAT_APPID=wx... npm run build --prefix wechat`。不要提交 AppSecret、上传私钥或管理员凭据。

`wechat/src` 是微信平台界面与系统适配；战斗、属性、培养、存档、角色骨骼、表情、治疗和开罐特效直接复用仓库现有模块。构建把图集转为 PNG、背景转为等比例 JPEG，敌人图集只打包骨骼动画使用的原始一列。每个美术分包预算3.8 MiB，主包预算4 MiB，整体预算20 MiB，超过即构建失败。具体尺寸和校验值见生成的 `BUILD-REPORT.json`。

## 验证边界

自动化检查覆盖 Canvas 启动、界面点击、拖动换位与继承、升级费用、存档导入与备份、生命周期、资源加载失败重试以及包结构。Canvas 模拟环境和浏览器截图不能代替微信开发者工具或手机的性能与兼容验证。

## 上传与发布

测试号可导入调试的权限以微信开发者工具实际提示为准。正式发布需目标小游戏账号及开发权限。使用开发者工具上传需管理员/开发者登录；CI 上传需该 AppID 的代码上传私钥与 IP 白名单。AppID 本身不提供上传权限。正式平台审核、资质和上线条件应在目标账号后台确认。
