## 用户新增联网要求后的实现边界

上述奖励目前仍在客户端结算，是联调基础，不能防止修改本地存档、清档、重新导入或伪造客户端。
“商业联网版”需要补齐以下能力再放行：

1. 微信身份鉴权，由服务端建立用户身份，禁止以客户端提交的 openid 作为身份依据。
2. 云端权威存档：鱼币、物资、培养、战斗进度通过服务端命令写入，客户端不能整包覆盖资产。
3. 服务端时间计算挂机收益、广告日限与冷却；事务、幂等请求、版本冲突处理。
4. 广告发奖须验证平台支持的服务端凭证/回调方案。客户端 `isEnded` 只可作为展示结果，不能作为服务端可信凭证。
5. 断网进入重连界面；未确认的领奖保持待确认状态。联网后从云端恢复，不以本地时间补发资产。
6. 真机验证：iOS/Android、弱网、切后台、杀进程、多设备登录、重复请求和广告无填充。

当前尚未接入云端登录、云存档或服务端发奖。不得把目前版本描述为强制联网或云端防作弊版。

## 配置与验证

开发构建：`npm ci --prefix wechat && npm run build --prefix wechat`。
测试：`npm test --prefix wechat`。
广告联调：通过安全环境配置 `WECHAT_APPID` 和 `WECHAT_REWARDED_AD_UNIT_ID` 后重新构建。
不要把账号密码、AppSecret 或代码上传私钥写入源码、存档或聊天。
