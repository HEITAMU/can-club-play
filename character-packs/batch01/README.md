# 第一批伙伴角色包 · v0.1.0 review

10 名角色：橘座、阿墨、奶盖、火花、薄荷、螺丝、玄岳、星斑、夜航、砚台。32 个技能加 10 个普通攻击的独立动作/效果预览。现阶段为角色资产与动作原型，未替换正式游戏战斗、经济、存档或微信工程。

## 查看

在仓库根目录启动静态服务器，打开 `character-packs/batch01/`。预览默认打开玄岳的蓄盾轰拳，可切换角色、技能、暂停、拖动进度，也可以手动补盾、补满能量、施加控制及解控。

`review/batch01-motion.mp4` 为实际渲染器录制，包含十位伙伴大技能、玄岳普攻和受控打断。`review/lineup.png`、`review/ultimates.png`、`review/xuanyue-sequence.png` 为同一渲染器输出，不是概念图冒充运行画面。敌方木桩是演示靶子。

## 玄岳

原角色 `pudding` 保留内部 ID，只改显示名与技能设定，避免将来迁移时丢失旧角色等级。

- **护体劲**：能量满自动消耗 100 能量，给自身添加最大生命 35% 的护盾，蓄力中照常执行。
- **蓄盾轰拳**：新获得护盾使当前盾量达到最大生命 30% 时蓄力，期间停普攻。开始之后再获得累计最大生命 15% 的有效护盾，锁定这一刻的实际盾量并出拳，命中敌方所有存活目标。
- **返劲**：护盾实际承受敌人伤害回复 12 能量，间隔至少 0.8 秒。驱散、加盾和自身技能不产生返能。

重拳不消耗能量。原型伤害为 `100%攻击力 + 160%二次触发时的护盾`，受护甲与护甲穿透影响。盾量上限 80% 最大生命，最短蓄力 0.9 秒，等待第二次触发最多 4 秒。出拳或中断后 8 秒内不能再次蓄力。以上均为可配置测试数值，尚未验证正式阵容平衡。

控制在命中前取消蓄力和待发重拳；解控后普通攻击恢复，不自动补出旧拳。第一笔启动护盾不重复计入二次触发；无效溢出盾不计入；二次触发后增减盾不追溯改变已锁定伤害。宿主战斗需在同一帧先处理控制，再处理命中。伤害事件由宿主按目标 ID 结算一次。

## 动作与特效

3 个可复用体型基础，头、两臂、尾巴独立运动；近战普攻有接近、挥击、命中、归位。玄岳蓄力时右拳后收，出拳时身体前压、右臂前伸，拳压在拳头前送后才展开。半场拳压、全体受击、碎盾、地面裂光和短促震屏有各自时间段，未采用旧黄色月牙。

| 角色 | 大技能视觉 |
|---|---|
| 橘座 | 我方护阵展开，五面护盾连成屏障 |
| 阿墨 | 三轮密集鱼箭与瞄准印，集中猎杀一个目标 |
| 奶盖 | 全队奶沫、弧形治疗流、上浮治疗粒子 |
| 火花 | 敌方半场火场展开，火舌与余烬持续流动 |
| 薄荷 | 半场冰晶依次长出，霜层与碎冰收尾 |
| 螺丝 | 大齿轮锁定、护甲碎片和扳手重击 |
| 玄岳 | 沉身蓄拳、横推半场拳压、全体受击与碎盾余波 |
| 星斑 | 我方星座连线与落下的供能星光 |
| 夜航 | 接近目标、三次大幅直线斩击，单点爆发 |
| 砚台 | 半场墨池、重印和溅起的墨屑 |

单体大技能仍只有单体受击，范围大技能才展示整片命中。普通攻击与小技能保留各自节奏，规模低于大技能。

## 已保留的美术修正

- 星斑仍使用最初 `star-v1`，没有采用后续帽子重绘。
- 火花保留原披肩，右手握提环，灯身在拳头下面独立摆动。
- 薄荷保留原清晰身体、头部和长袍，仅用高清组件修正左手持杖；空手为右手，法杖在袖口外。
- 玄岳的新四种头部都来自自身深灰虎纹图集，不会在攻击时切回旧布丁头。
- `source/` 是选定原稿的无损 WebP，`assets/` 是运行时图集；裁切、打包、缩放不重画素材。生成与修改提示记录在 `prompts.json`。
