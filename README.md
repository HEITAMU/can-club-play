# 罐头远征队

原创猫猫放置冒险，网页试玩版 v0.19.0。五猫阵容、自动战斗、救援技能、培养继承、首领装备、离线鱼摊。

内容包括 8 位队员、12 种装备和 120 个参数化组合关卡。使用本机浏览器存档，可在游戏设置中导出备份；没有广告、支付或云存档。

本仓库仅包含公开试玩站的前端文件，不包含账号凭据。角色、图形和界面为本项目制作。

## v0.11 五人阵容与一屏战斗

- 最多上阵五只猫，前两位为前排，后三位为后排。敌人普攻在两名存活前排之间轮换，起手后锁定目标；目标倒下时重新选择存活前排。后排按阵容顺序补位，位置没有属性加成。
- 猫与敌人的位置以脚底落点为准，统一缩小人物、保留贴地阴影，调整六景取景使所有落点位于地面。待机呼吸围绕脚底变化，不整体上下漂浮。
- 攻击表现使用近战贴近挥击、飞鱼弹体、火焰、冰晶、电光、治疗、护盾与星光；没有连接施放者与目标的指示箭头。技能名显示在施放者头顶，命中处显示效果。点击战报可查看角色名、技能名及实际目标。
- 首页采用一屏布局，包含战场、开罐啦、五人训练卡、小鱼摊和导航；猫队、街区等长列表和弹窗单独滚动。小屏高度不足时训练卡使用紧凑样式。
- 普通关卡有 1、2、3 或 5 名敌人；第 16 关起，符合每四关波次的非首领关出现五怪，整街区首领带四名护卫。五怪波次的单体生命和攻击按编队缩放，避免人数增加直接变成伤害数倍。
- 新队员仍从 1 级开始；替换可继承已付出的培养，既有三人存档的等级、鱼币与阵容原样保留，可手动添加第四、第五位。存档版本与存档键不变。
- 运行原五组测试及 `tests/five-crew.test.mjs`，覆盖五人保存/继承、双前排锁定与补位、五怪波次、群体技能目标与特效时序。120 关自动模拟仅作可运行性检查，不代表留存或难度已经验证。
