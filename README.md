# 罐头远征队

原创猫猫放置冒险，网页试玩版 v0.3。三猫阵容、自动战斗、救援技能、培养继承、首领装备、离线鱼摊。

内容包括 8 位队员、12 种装备和 120 个参数化组合关卡。使用本机浏览器存档，可在游戏设置中导出备份；没有广告、支付或云存档。

本仓库仅包含公开试玩站的前端文件，不包含账号凭据。角色、图形和界面为本项目制作。

## v0.2

- 救援技能明确显示回血 20%、攻击敌人、打断蓄力；首次使用前提供提示，不耗鱼币。
- 低等级队员替换高等级主力时，双方交换等级：20 级橘座被 1 级火花替换后，火花变为 20 级，橘座变为 1 级。培养投入完整转移，不额外送等级、不耗鱼币。
- 移动已上阵队员的站位、加入空位、替换较低等级队员时，等级保持不变。按钮提前显示具体等级变化。
- 队员档案也提供单独的「继承其他队员的培养」，可转入任一已解锁且等级更高队员的培养；出战位置不变。
- 旧存档原样兼容，保留鱼币、等级、阵容、关卡与奖励记录。继承不计入付费训练次数，不重复发奖励。

测试：`node tests/core.test.mjs`、`node tests/inheritance.test.mjs`。

## v0.3

- 普攻统一优先攻击存活的前排，前排受到直接伤害减免 20%；倒下后顺位接替。首领群攻保持蓄力预告和打断窗口。
- 战场采用一前两后站位、敌人目标标记、前排减伤标记与格挡反馈。
- 接入全新绘制的 8 位猫队员、12 个敌人外观和屋顶战场；保留各自呼吸、受击和技能反馈。六街区目前沿用同一屋顶底图并调色，尚非六套独立场景。
- 单独继承等级时保持现有生命与护盾比例，避免反复继承获得免费治疗。
- 新素材共约 1.1 MB，WebP 格式。源码与素材位于本仓库，存档格式保持兼容。

额外测试：`node tests/frontline.test.mjs`。
