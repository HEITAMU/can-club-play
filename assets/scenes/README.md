# 手绘街区背景 v0.19.0

- `streets-v019.webp`：1254 × 1254，3 列 × 2 行，每格 418 × 627（竖向 2:3）。
- 顺序：晒鱼天台、午夜鱼市、霓虹小巷、纸箱仓库、旧城钟楼、月光车站。
- 基于原 `assets/painted/streets.webp` 和现有猫咪图鉴作风格参考，通过内置图像工具重绘。保留墨线、水粉纸纹和傍晚旧街氛围，增加街区间的色彩差异。
- 生成约束：正方形总图、等宽三列两行、每格独立竖向构图、空旷战斗地面、无角色文字和界面。保持原画风，使用陶土红、藤叶绿、暖灯黄和蓝紫夜色；不采用被否决的光滑卡通方案。
- WebP 仅作编码压缩；没有拉伸或改变生成图中的物体比例。
- `paintedScene` 使用各格的 SVG viewBox 和 `xMidYMid slice` 等比裁切；不再分别拉伸横纵轴或额外拉高容器。
