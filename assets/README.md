生成描述：

- 猫队员：原创精致手绘 2.5D 猫冒险家，统一体积、皮毛、衣料与装备质感。橘猫锅盖守护者、黑猫弓手、白猫奶盖治疗者、护目镜辣椒罐爆破者、薄荷冰法师、蓝灰机械师、胖猫鱼盾守护者、紫猫星星法师。四列两行，完整身体，透明背景，无文字，保持格内构图。生成后以图像编辑工具清除背景，并保留人物和排列。
- 敌人：参考猫队员的材质与绘制质量。灰尘团、纸箱、拖把、电池、纸袋、无人机，以及吸尘器、冰柜、招牌、纸箱首领、闹钟、售货机。四列三行，独立透明剪影，统一斜正面视角，首领有皇冠。
- 战场：蓝调夜间的城市屋顶，手绘 2.5D 质感，青蓝石砖地面、远城与月亮、周边鱼箱盆栽和暖色灯光。中心与下方保持空旷，服务一前两后的战斗布局，不烘焙角色、血条或按钮。

当前限制：角色动态为程序控制的呼吸、受击、投射物和技能特效；六个街区仍共用同一屋顶底图并调色。
