# 伙伴身体与表情 v0.15.0

四张 1024×1536 WebP 图集，按橘座／阿墨、奶盖／火花、薄荷／螺丝、布丁／星斑成对排列。`anatomy-data.mjs` 记录实际透明轮廓包围框；切分按连通部件确定，不能假定原图每条网格线都精确对齐。

每只猫使用独立的无前臂躯干、左侧持械臂、右侧自由臂、尾巴和一个头部。盾手的爪与前臂遮在盾后，盾后仅露出连接肩部的小段。布丁躯干没有锅盖；锅盖头盔只存在于各头部。弓手左臂握弓，右臂拉弦；弓弦和箭以两条手臂变换后的连接点绘制。

表情索引只有 `neutral / blink / attack / skill / hurt / victory / down`。删除了含泪受控格。攻击头另绘咬牙与压眉，避免与平静表情重复。所有素材用内置图像生成完成，技术脚本只做透明边界提取、等比例缩放和图集打包，不绘制或修改角色五官。

`portraits.webp` 是同一游戏渲染函数输出的待机图集，供首次加载展示，避免闪回旧身体。运行版图集不包含被否定的身体或含泪表情。

生成约束：手绘平面 2D、暖棕描线、干笔淡彩、三分之四正面朝右；每个部件独立、肩部连接明确、禁止把两只手画进同一手臂格；四列六行的双角色部件与表情图集，第二组三行重复结构。头盔只在头部，躯干没有额外锅盖；不画受控含泪表情。

最后一轮攻击脸编辑要求：保留八个角色的头型、毛色、耳朵与帽子，四列两行透明头部图集；仅改眼眉与嘴，眉毛向内下压，瞳孔朝右，嘴为小而紧闭的咬牙表情，露出细条白色牙齿和一颗小尖牙，不张口喊叫、不吐舌、不微笑、不流泪、不出汗。没有身体、手、武器或文字。

重打包：`node scripts/pack-anatomy.cjs <A.png> <B.png> <C.png> <D.png> [attack-heads.png]`。前四张为最终修正版，最后一张可替换八个攻击头。原始生成图并非运行依赖，提交的 WebP 和坐标即完整运行资产。

复核：`node scripts/render-anatomy-review.mjs` 使用真实游戏 `renderPuppetFrame` 输出整只人物和七种表情，并更新加载图。`qa/` 是不提交的临时检查图。本地 Canvas 检查不等于浏览器、微信或真机验收。
