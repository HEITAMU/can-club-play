# 罐头远征队 · 升星、等级与技能自动解锁

**当前规则：升星解锁角色等级上限；达到指定角色等级时，技能自动解锁或升级。** 不再需要点击“研习”，没有单独的技能升级花费。对应 2026-11-19 用户补充要求：“到等级以后自动解锁，就咸鱼之王那种的”。

## 升星与等级

升星仍使用原猫牌、信物和训练笔记，只提高角色可培养的等级上限；不直接提高等级、生命或攻击。

| 品质 | 等级上限 |
| --- | ---: |
| 精英 | 10 |
| 精英+ | 20 |
| 史诗 | 30 |
| 史诗+ | 40 |
| 传说 | 60 |
| 传说+ | 80 |
| 神话 | 100 |
| 神话+ | 120 |
| 巅峰 | 140 |
| 巅峰+ | 160 |

## 技能自动解锁

| 角色达到的等级 | 自动生效的技能阶段 |
| --- | --- |
| Lv.1 | 基础技能 I |
| Lv.5 | 原有被动技能自动开启 |
| Lv.40 | 核心绝活 II |
| Lv.80 | 核心绝活 III |
| Lv.120 | 核心绝活 IV |

原有 40 / 80 级天赋同样按角色等级自动开启；它们与绝活阶级是不同机制，保留原数值。进入新等级时，绝活效果立即按最新阶段参与实际战斗，无需任何确认或消耗勋章、笔记、印石。跨过多个解锁门槛时直接取当前等级对应的阶段。

角色页展示当前技能效果和下一次自动解锁等级，技能详情列出四级效果，不提供“研习”按钮；达到 120 级后显示全部解锁。无法通过调用旧的手动研习方法取得额外等级。

装备强化、升星、升级鱼币价格、关卡敌人和掉落没有因这一条规则额外修改。角色属性仍随等级变化，升星本身不会造成即时生命或攻击增长。40、80、120 节点的技能增强会使跨节点的战斗表现发生变化；尚未把整月玩家经济与难度体验判定为最终平衡。

## 继承与旧存档

继承交换等级，技能效果自动按交换后的角色等级重新计算，不再转移单独研习的等级。双方仍需满足接收等级的品质上限；上限不足时只替换阵容，不会偷偷移动培养。

继续使用 `can-club-growth-preview-v1` 存档格式及其备份。原有一次性的品质强度转等级转换和超上限旧档保护仍有效。新增 `skillUnlockRuleVersion: 1` 仅用于把旧手动技能研习改为自动规则，不与 `growthRuleVersion: 1` 混为一谈。

旧玩家曾手动购买的研习档位，迁移时按照**各档原价逐档返还**：技能 II 为 8 勋章、50 笔记；III 为 20 勋章、140 笔记、6 印石；IV 为 40 勋章、300 笔记、18 印石。旧版最高三级的累计返还为 **68 勋章、490 笔记、24 印石 / 位伙伴**。这是一次性的资源返还，重复加载、备份恢复和再次保存不会重复补发；未购买档位无返还。自动技能阶级按实际保留等级确定，因此旧版已购买、但角色等级还未达到节点的高阶效果会暂时按当前等级生效，直到培养达到对应等级；过去支付的资源已退还。
