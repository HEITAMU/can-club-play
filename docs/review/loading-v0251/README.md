# v0.25.1 验证记录

## 本轮行为

- JS 依赖图合并为 1 个浏览器模块，9 份 CSS 合并为 1 份。8 位伙伴的动画图集及头像共 16 项，从 8,606,906 字节减为 1,915,168 字节。原画与动作数据未更换。
- 图片统一排队加载（并发 3），超时/错误会退避重试；列表头像延迟加载，隐藏人物不持续绘制。人物光栅绘制最多每秒约 30 次，新动作帧、尺寸变化和图形上下文恢复即时绘制。特效到进入战斗才加载。缓存安装只预取页面及两个包，不抢先下载全量美术。
- 战斗飘字由实际命中、治疗、护盾事件产生，跟随战斗时钟移动和淡出，不依赖 Web Animations；暂停时保留。
- 委托结算显示奖励并返回原分组/关卡/难度。Web 可立即点返回或再战；自动返回等待 1400 毫秒。手动导航或再战取消旧回调。
- 换装移入伙伴：五个装备位围绕人物，旁边直接选择未装备物品。背包装备页仅列未装备物品，按全部/五部位及套装筛选，材料另页。换装后被替换物品重新进入未装备列表。
- 套装名称使用共同前缀；每套四件装备各有独立短故事片段。详情保留词条、套装/妙招效果、必要操作和末尾故事。街区选择只显示名称和掉落图标，删除重复玩法说明。
- 属性、百分比、资源、伤害、治疗、护盾、能量使用整数结果。装备卷值改为整数 80–120，旧版本小数词条只迁移一次。持续收益、灼烧与蓄能使用整数余数，避免频繁结算增发/丢失。动画插值与内部运动时钟仍按连续时间运行。

## 难度对照

`patrol-balance.json` 保留 5 个固定种子下的普通关末关对照。装备、星级和突破保持相同：130 级普通阵容 0/5；相同阵容升至 160 级 5/5；130 级护盾反击、破甲、灼烧组合 5/5。

`balance.json` 保留 56 组五人阵容 × 5 种种子 × 6 场最高难度硬仗的 1680 场模拟。冷库封锁 91/280、补给线争夺 54/280、铁壳拦路 84/280、同频警报 123/280、断电追兵 63/280、钟楼围困 107/280；每关都有多个全种子可过组合和大量失败组合。这是固定装备、固定站位规则及救援策略的压力模拟，不代表实际玩家胜率。

## 尚未验证

本轮浏览器运行环境不可用，未完成真实 DOM 布局/交互截图或手机浏览器复测。iPhone 与微信真机帧率、弱网耗时、微信开发者工具未验证；体积减少和逻辑回归不能等同于这些实机指标。原生构建仅供后续开发者工具测试，没有上传微信正式版。非养成奖励关继续延后，不新增奖杯。
