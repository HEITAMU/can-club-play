# v0.27.5 成长反馈与材料简化

## 本版已实现

- 技能只扣训练笔记，三次消耗 120 / 420 / 1330，满级仍是 Lv.4。Lv.3、Lv.4 的原印记来源在第 120 关开放；简化后明确保留第 120 关条件，已学会的技能不会降级。
- 升星只扣专属信物，每星 20 / 40 / 60 / 90 / 130，共 340；从原来的五次小投入加一次进阶改成一次完整升星。每星累计生命、攻击增益仍是 4 / 8 / 12 / 16 / 20%，没有把后几星的收益挪到第一星。
- 为避免低级攻击基数太小而取整成零，完整星级的攻击增量至少为每星 1 点（装备倍率前）。基数足够时仍按原百分比；不会给后期平添额外乘区。
- 弹窗按实际 catStats 计算升星前后攻击和生命；成功后保留本次变化，下方仍可看下一星。伙伴猫牌按已获得的星数显示。
- 旧勋章按 1:5、旧印记按 1:20 转为笔记，对应关卡按同率改掉落，重复奖励次数不变。两种原笔记类委托归在训练笔记分类，硬仗保留挑战分类与原首通装备。
- 已投入爪印的信物抵扣剩余升星成本；旧升星笔记返还一次。存档版本 2 标记避免重复返还；已有星级、被动、技能与装备保留。
- 教程后的目标衔接：仓库装备 → 穿上指定首件装备 → 奶盖 → 上阵伙伴 5 级被动 → 强化 +3 → 继续主线。修复无法推进的旧战利品任务，已领取标记不清零。

## 成长时间边界

旧单伙伴全部技能与升星的材料按迁移汇率折合：490 笔记 + 560 升星笔记 + 68 勋章 × 5 + 24 印记 × 20 = 1870 笔记。新技能总需求也是 1870。只是等价预算相同，不代表各种游玩方式下耗时完全相同：旧材料分开积攒有瓶颈，新材料可通用，会改变玩家的最优路线。

信物时间约束没有减少：六档首通共 122；新伙伴结识用 20，剩 102；满星还差 238。最终档每次 6、每天 3 次，需要 40 次领奖，分布在至少 14 个领奖日。此处假定已开放并能打过最终档（第 220 关），不把推关时间算作零。原版相同。每个伙伴独立配额不变。

满星上限、技能上限、装备强化 +15、主线 600 关、角色等级 160 以及中后期敌人数值未整体下调。后期插件、妙招牌尚未实现，不以占位道具冒充上线；它们应承担改变组合和打法的成长，而不是继续堆基本属性面板。
