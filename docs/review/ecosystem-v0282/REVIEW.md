## 实现

- 品质升阶：精英 / 精英+ / 史诗 / 史诗+ / 传说 / 传说+ / 神话 / 神话+ / 巅峰 / 巅峰+。参考《剑与远征：启航》同角色信物与公共资源的升阶结构，不声称照抄原作数值。费用已按本作每日 3 次、5 信物奖励重新配置。角色页删去“下一次升星”提示，升阶弹窗仍显示准确前后属性与消耗。
- 两套五人阵容合计覆盖八角色：飞鱼破阵（主养阿墨），护盾震街（主养石墩）。可一键上阵已拥有成员；不赠送角色，不自动花钱或搬移装备。成长提示优先主养角色。
- 失物追寻：全队每天共 3 次胜利领取，每次随机一位伙伴 5 个信物；北京时间零点刷新，失败不扣次数。每次胜利结算可完成真实激励视频后额外自选 5 个信物。SDK 必须明确 isEnded=true；无广告配置时不给自选奖励。持久化凭据防同一存档重复领取，不宣称具备云端防作弊。
- 信物专页：八种角色关联图标，点击说明及“邀入远征队”；20 个激活，已拥有则前往品质升阶。
- 开罐固定为每个存活己方回复 40 HP、每个敌方造成 50 固定伤害，保留打断、原动作和能量效果；冷却 5.6 秒。增益和护甲不改变固定数值，护盾正常吸收伤害，不能复活。
- 开罐图标战场底部居中放大；Boss 总血条上移、保留头顶小血条。按钮和四个导航分别使用短促低音量音效。
- 主线同类敌人基础生命和攻击线性增长，不追随玩家战力调整。五阶段材料委托顺序解锁，风险色阶由浅到深。原三条装备路线和每日轮换、妙招搜索机制保留。
- 修复结算恢复时新手引导拦截奖励选择；信物图标纳入进场预加载，共享素材仍低于 2 MiB。

## 验证

385 项 Node / 微信原生 Canvas 测试通过，0 失败。包含 36 个旧猫牌组合不掉档、保存再次读取不重复迁移、每日 3 次、跨北京时间零点、倒拨时间、奖励幂等、真实战斗数值与两套阵容覆盖。
微信测试需要先运行 node scripts/build-wechat.mjs，以确保测到最新 runtime.js。

浏览器在 355×700 视口检查战场、Boss 两种血条、开罐位置、背包信物、详情到升阶、一键阵容切换、结算自选与无广告时不发奖。截图见同目录。测试页使用内存存档，不覆盖玩家真实存档。实际试玩页已经打开并正常进入战斗。

team-balance.json 是固定装备、全员已拥有、等级 5、仅提高主养角色品质的对照模拟，不是实际玩家养成时间预测。两套阵容均能通过八类委托的第一阶段；升阶推进幅度随阵容与关卡而异，不保证每次固定过百关。后期百万级伤害验证使用街区硬仗，不再用现已线性化的主线末关充当原指数难度。
未进行 iOS/Android 微信真机和真实广告填充验收，不宣称稳定 60fps。
