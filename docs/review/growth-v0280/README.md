## 成长

- 升级平缓增长，默认一次升 1 级。基础生命/攻击倍率：Lv.1 100%，Lv.10 140%，Lv.20 175%，Lv.40 225%，Lv.80 275%，Lv.160 325%。取消等级整十跳涨与对应加价。
- 升星仍是五次点亮后单独进阶；布绳 → 铜 → 银 → 金 → 琉光 → 曜金顺序不变。原信物/笔记总消耗不变。点亮与进阶均有真实数值增幅。
- 布绳阶段倍率依次为 100%、240%、380%、540%、720%、950%，进阶铜牌为 1200%。后续相对增幅逐渐放缓；完整表在 `growth-curve.mjs`。
- 升星卡片显示当前/下一星以及真实生命、攻击前后值；成功反馈显示战力变化，推关计数在升星时开始计算。
- 银牌阶段界面开始提示装备重心；普通装备 +1～+15、套装与妙招牌继续生效。妙招牌机制沿用上一试玩版。
- 主线固定 3500 关；重新分配前段关卡密度，敌人不按玩家战力浮动。
- 已有试玩存档保留等级、星级、材料阶段和关卡进度。为旧等级突增投入补回达到相近培养倍率所需的升星材料，退回等级突增加价。玩家自行点亮，不自动跳阶段。迁移只发生一次。

## 引导与结算

- 奖励详情居中浮在结算上，外侧点击、关闭、Escape 只收起详情，不误关结算。
- 原穿戴目标错误地检查“背包还有未穿装备”，换下的旧装备也会触发。现在成功穿戴即持久记录完成；再掉装备、脱下装备、重启都不会重新要求完成穿戴教学。
- 兼容旧存档已经穿戴的奖励、已完成/跳过的装备教学。
- 委托、擂台和周常的当前战斗优先显示；失败、退出、胜利后停止显示旧活动。手账与底栏使用同一判断。
- 有足够升星材料时指向实际可升星伙伴；材料花完、满阶、换入活动时更新。主线通关后改指向街区硬仗。结识伙伴任务选择尚未结识的人。

## 验证

- 全量 364 项测试通过；最终补入主线通关边界后，引导及打包专项 15 项通过，共 365 个独立测试。
- 网页代码构建通过；微信构建主包 264391 字节，总计 20075575 字节，6 个资源分包。此为构建和运行时测试，不是微信真机验收。
- 五组固定种子、真实 Battle、0.1 秒步进、两只 Lv.5 初始猫和原装备：阿墨第一颗星分别推进 180、160、140、180、180 关；其他升星并不保证每次都超过 100 关。
- 实际经济模拟使用正常关卡、任务、挂机及委托收益，先正常练到 Lv.5，卡关后升一星：18 次升星/进阶推进到第 1920 关。过程中有 12 次委托，无赠送资源、广告或罐头支援。此处继续获取信物受战力限制，开始需要装备/阵容提升；22.8 小时为引擎累计时间，不是留存数据。
- 同样两只 Lv.5、铜牌 3/5 的卡点：原装备停在 1920，换两阶精良套装并强化 +3 / +6 后停在 2080 / 2200。此比较更换整队四个普通部位，不能解释为单件强化收益。
- 固定五猫 Lv.40、银牌、三阶稀有套装：全套 +0 到 +6，五种子卡点从 2620 到 2720～2740；到 +15 为 2900～2920。升级十级的提升更小。
- 存档测试覆盖不改变猫牌材质、不重复补偿、下一星实际属性和材料扣除；引导覆盖穿戴后旧装备留包、后续掉落、卸装、读档、活动进出、失败、满阶及主线终点。
