# v0.28.0 成长试玩版

基线：v0.27.6，提交 `99ba272ce6bf703fdd9d5f8821b22a2db511d881`。
回退分支：`stable/v0.27.6-before-growth`。
源码分支：`experiment/growth-v0.28.0`。

## 试玩与回退

- 原版保持根路径 `/?v=0.27.6`；本版只发布到 `/growth-preview/play.html`。
- 网页使用 `can-club-growth-preview-v1` 保存，原版 `can-club-save-v1` 不读取、不写入。
- 存档封装为 `CAN-CLUB-GROWTH-1`，防止把实验数值误导回原版。新版本从新进度开始。
- 试玩不注册 Service Worker。`play.html` 文件名避开原版 Service Worker 对目录/index.html 的通用缓存回退；共享现有美术资源。
- 返回原版可以直接使用旧链接或试玩设置中的“返回原版”。撤掉 main 上的 growth-preview 目录即可取消试玩，原版源码和资源无须恢复。

## 本版规则

- 主线扩展到 3500 关；敌方强度按固定内容曲线设置，不随玩家战力浮动。
- 角色 Lv.10、20、30、40 为前期跃升点，按钮优先升到下一个跃升等级，并显示真实增幅。
- Lv.40 后角色的攻击、生命成长放缓，原有装备阶位、品质、套装、+1～+15 强化继续提供主要数值提升。没有合并材料，也没有修改猫牌每阶段五小步及铜牌等材质顺序。
- 培养后显示攻击/生命/队伍战力的前后值；战场记录本次跃升后真正推进的关数。
- 装备穿戴和强化即时更新当前战斗，保持生命比例，不重置妙招牌的一次性触发或冷却。
- 妙招牌不增加虚假面板战力：补上一爪每两次普攻追击；留口气开场能量和技能回能；垫层软布加强护盾；热乎一口加强低血量治疗并清灼烧；添把小火引爆灼烧；缩成一团每场挡下一次致命伤。
- 废件仓库难度 2 首通保底“补上一爪”，后续正常装备掉落仍有机会获得其他妙招牌。
- 美术、人物比例、动作资源与猫牌结构沿用 v0.27.6。

## 验证

- `node --test --test-reporter=tap tests/*.test.mjs wechat/tests/*.test.mjs`：352 项通过。
- `node scripts/build-web.mjs --code-only`：通过；原美术文件无差异。
- `node scripts/build-wechat.mjs`：通过；主包 262882 字节，总计 20074066 字节，6 个资源分包。此处不是微信真机验收。
- `node scripts/balance-growth.mjs`：真实 Battle 引擎、0.1 秒步进、五组固定种子，无罐头支援。
- 前期经济模拟只使用初始两猫、实际战斗/任务/挂机收入、失败后培养，无赠送货币、广告或委托奖励：八次培养分别推进 240、140、180、100、240、180、200、100 关，最终停在第 1480 关，双方 Lv.40。完整模拟约 15 小时引擎时间，不是实测留存或要求玩家连续在线 15 小时。
- 单独把阿墨从 9/19/29/39 升一级、保持其他条件不变，五组种子的推进量为 80～220 关；并非所有阵容和卡点都保证同一个推进数量。
- 中期固定五猫 Lv.40、3阶稀有套装：普通装备从 +0 到 +3/+6/+9/+12/+15，第一失败关逐步从 1840～1880 推进到 2420。此场景提升整队四个普通部位，不把整套提升伪装成单件 +1 的效果。
- 妙招牌相同面板战力可改变实际战斗结果；测试覆盖追击转火、不递归触发、两回合冷却、致命伤一次保护和不复活倒地角色。
- 完整数据见 `balance.json`，构建见 `build.json`。

后续需要根据实际试玩反馈再校准卡点密度、实际游戏时长和装备获取节奏；本版是可回退的成长试验，不替代原版。
