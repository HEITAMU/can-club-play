# 回合制战斗规则 v1（0.26.71）

一整轮双方存活单位各获得一次行动机会。控制跳过也消耗该机会；死亡单位退出队列。全局最多30轮，最后一轮完整结算。动画时钟只负责出手、命中、收招和特效，不负责战斗持续效果。离线收益、广告间隔和在线时长保留现实时间。

- 灼烧：目标行动前结算一次，持续2次机会。火花基础60%攻击/回合，觉醒90%，突破每级增加15%；40级灼烧强化照常乘算。保留总基础伤害120%/180%，重复灼烧不叠层。击杀不再重复结算。
- 眩晕：跳过目标下一次行动；薄荷保持1回合控制，觉醒改为主动技能增加30%攻击倍率（230%→260%），避免延长为2回合形成连续封锁。打断首领后重新等待3次行动。
- 火花减疗：施放当轮和下一轮，治疗降低50%。
- 暖窝：每2次自身行动机会回复5%最大生命，保留治疗加成。炉边：暴击灼烧30%攻击/回合，持续2回合。
- 留口气：主动技能回复6能量，冷却2轮。普通受击回能每轮最多8，持续伤害/反伤不触发。
- 石墩：护盾达到30%开始蓄力；蓄力每次自身行动前回复50能量，再获15%生命护盾准备重拳。自身施盾与出拳各占一次行动；盟友帮助时最快下一轮出拳。重拳/中断后的再蓄力冷却2轮。护盾破裂或控制中断。原画、出拳命中时机、伤害倍率保留。
- 首领：第3次行动蓄力，下一次行动释放155%攻击群攻；释放后3次行动再次准备。蓄力让出行动权，其他单位能出手打断。
- 补给员：每2次行动治疗前排，治疗占用本次行动，不追加普攻；控制期间不治疗。
- 冷库：每3次行动机会补盾；该次开始有灼烧时不补盾（即使正好是最后一跳）。
- 开罐支援：冷却3轮，开场可用；打断蓄力并眩晕1回合。
- 拖把迟缓：将本轮尚未行动的目标移至队尾，不延长动画。
- 长局加压：前10轮不加压，第11轮起双方伤害每轮增加25个百分点；取代旧的40秒后持续加压，不因动画速度不同而改变伤害。

验证：277项自动测试（修订原按秒断言并新增7项回合用例）；30/60Hz完整战斗事件、生命与胜负一致；暂停不推进；控制/灼烧/蓄力互斥与冷却覆盖。主线600关5个固定种子：普通搭配130级失败、相同搭配160级通过、护盾破甲灼烧140级通过。见 review/release-v02671/balance.json。模拟结果不代表玩家胜率，也不是微信真机性能验收。

旧 shield-punch 独立演示仍保留时间驱动作为历史动作对照；H5与微信正式战斗均显式启用roundBased，历史演示不得代入战斗平衡。
