# 拽一下星空 · 独立试玩

《星图有点乱》的独立玩法实验，入口 `fourfold/sky-pull-preview/index.html`。不接入主游戏入口或存档。

按住星空任意位置拖动，附近的星星随星空一起被拉动；松手后向相反方向弹出。星星经过空心星座位置就会归位。拖动时显示预计轨迹和落点，能归位的目标会发亮。只有拉、放两种动作，没有计时、步数限制、道具或惩罚。

共 3 个自由选择的小场景，从一颗到三颗星，均能一拉完成。失手后可以从当前位置继续拉，也可以重新开始。手势提示展示起始位置的一种可行拉法。键盘使用方向键拉动、空格或回车松手、Esc 取消。

## 实现

- 规则：`../cocos/assets/scripts/SkyPullCore.js`，纯 JavaScript，使用 1000 × 1000 逻辑坐标，方便后续 Cocos Creator 3.8.8 接入。
- 画面：`cloth.mjs` 使用带局部形变的纹理网格；WebGL 不可用时切换 Canvas 2D 三角网格。边界固定，拖动与回弹带动星云纹理和星尘。
- 素材复用既有 `home-title-starmap-v1.webp`、`starlight-preview/assets/tile-v1.webp` 及主游戏音乐、音效模块。
- 只有声音偏好保存到 `STARMAP_SKYPULL_SOUND`，不读取或改写其他模式的进度。
- 画布像素比上限 1.7，粒子数量上限 72；页面隐藏时暂停动画和音频。

## 验证

`node --test fourfold/sky-pull-preview/core.test.mjs`：6 项通过，覆盖三个场景可解、反向弹出与距离衰减、手势容差、沿路径捕获与目标独占、已归位星星固定、极小拖动和边界限制。

浏览器已检查 320 × 568、390 × 720 两种尺寸，无横向或纵向溢出；检查了拉放通关、下一场景与重新开始。云端浏览器实际使用 Canvas 网格回退路径。尚未在实体手机、微信或 Cocos Creator 导出包中验证，WebGL 路径也未在该浏览器实际运行。
