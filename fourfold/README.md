# 四格诡局 · FOURFOLD

微信好友同关挑战 × 3×3 四格旋转益智游戏。目标：转动任一 2×2 方块（顺时针或逆时针），用尽量少的操作把九枚印记归位，争夺真实好友最优解。

> 工程版本：**Cocos Creator 3.8.8**。网页试玩和 Cocos 小游戏通过 `cocos/assets/scripts/Core.js` 与网页的 `CoreHardWeb.js` 使用一致的规则与固定题库。网页试玩版不冒充 Cocos 渲染版，微信好友榜与微信广告仅能在微信小游戏内运行。

## 试玩

[打开公开试玩](https://heitamu.github.io/can-club-play/fourfold/?v=0.8.38)，直接用手机或电脑浏览器开玩。建议手机竖屏。键盘 `1–4` 旋转四个位置、空格切换旋转方向、R 重开。本地静态预览可使用 `python3 -m http.server 8000`。

## 0.8.27 手机转动与无声排查

- 修复系统“减少动态效果”暗中将主游戏 2400ms 旋转改为 240ms 的路径。游戏默认完整旋转，设置可手动选择轻柔淡化；两种模式都持续 2400ms，偏好存为 `fourfold:turnMotion`。
- 不再让一次永不结束的音频 resume / suspend Promise 阻挡后续所有手势；恢复和单次播放等待均有时限，超时只放弃旧触点。鼠标与触摸采用对应的激活时点，触屏不再在 pointerdown 抢先锁住恢复流程。
- 音效设置增加明确选择的手机兼容试听。标准模式沿用系统音频类别；兼容模式在支持 AudioSession 时请求 playback，否则复用一个 HTMLAudioElement。兼容模式按媒体音量播放，可在设备静音模式下发声；停止、离页或恢复标准模式时释放自己设置的会话类别，游戏音效开关仍有效。
- 设置显示实际主脚本与音频模块标识、最近旋转实测耗时，以及按下、落位、试听各自的请求状态。它们来自当前运行实例，不从地址栏版本或 Chrome 波形推断用户手机已出声。
- 这轮不修改音效样本或音量。入口调查、原因与验证边界见 `cocos/docs/mobile-motion-audio-recovery.md`。

## 玩法闭环

- **18 份闯关档案**：完成当前局面才解锁下一关，存档自动保存至本地。
- **每日同题**：固定 UTC+8 日期，保证同一天每个人拿到完全一样的题目；分享时携带日期和挑战步数。
- **真正的最优解**：9! 个合法排列组成的状态图，使用双向广度优先搜索；理论最少步数与实际提示均由算法算出，非凭空设定。
- **荣誉**：最优解、极致推演、逻辑高手、破局者；理论最优与玩家得分显示分开。
- **公平分数**：主要比较步数，相同步数比较用时；普通关5次、每日挑战2次的每局提示额度内正常参与排行，提示不扣分。上传本机今日最佳，较差的重试不会覆盖该纪录。
- **自愿分享**：公开战绩+同题链接，不做强制分享、转发后解锁、邀请奖励、虚构好友。
- **分阶段提示**：未开通广告时正式版本也免费提示；开通后配置真实广告 ID 并显式切到激励视频模式。两种模式共用每局额度，提示始终不影响排行，结算 Banner 单独可选。

## Cocos Creator 打开方式

1. Cocos Dashboard 安装 **3.8.8**，选择“导入项目”，目录指向本仓库的 `cocos/`（其中包含 `package.json` 和 `assets/`）。
2. 在资源面板打开 `assets/scenes/Main.scene`，点击 **预览**；场景会由 `Game.ts` 创建 Canvas、UI、相机和交互按钮。
3. 打开「项目 → 构建发布 → 微信小游戏」，填自己的 AppID，勾选“生成开放数据域工程模版”，构建。`build-templates/wechatgame/openDataContext/index.js` 应当拷贝进构建产物。
4. 完整发布流程见 `cocos/docs/RELEASE.md`。`Game.ts` 默认 `HINT_MODE='free'`、`AD_IDS` 为空，未开通广告也能以免费提示模式上线；取得真实广告位后，再切换 `rewarded` 模式并重新构建、真机验证。
