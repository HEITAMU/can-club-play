# 七套星图实时试转模板

版本：0.8.13；更新：2026-11-21。采用第3、4、5、7套最新定稿，默认打开「逐星之鹿」。

## 查看方式

- `tests/interactive-board.html`：项目内预览页，通过静态服务器打开，读取当前主题配置和资源。
- `art-source/previews/fourfold-live-board.html`：可直接打开的离线完整模板。七张星图、棋盘材质、旋钮、样式与脚本全部内嵌，不需要服务器或外部请求。
- 消息内预览由同一个控制器打包，使用原尺寸AVIF编码控制传输体积；离线模板使用项目现有同尺寸quality95 WebP。两者共用构图、坐标和旋转逻辑。

七套主题可切换；四个金色旋钮旋转相邻四格；可以选择顺逆时针、打乱、撤销、恢复拼合、隐藏数字以及查看完整原画。切换星图恢复到拼合状态。该页面独立维护试转状态，不读写游戏进度。

## 与正式棋盘的关系

`tests/interactive-board.js` 导出 `mountBoardPreview(root, {reference, themes, assetUrls, defaultTheme})`。根节点为 `#ff-live-board`；参考坐标、主题表和图片URL由宿主注入。

棋盘调用实际 `Core.js` 的 `rotate`，九块取图调用 `TileThemes.js` 的 `buildThemeArtwork`，旋转轨迹调用 `TurnMotion.js` 的 `createTurnMotion` 和 `sampleTurn`。九个槽位、四个旋钮位置与外框裁片均来自现有 `referenceLayout.json`，保留不等宽、不等高的原始槽位。

正常旋转仍为1200毫秒。四张图块沿旋钮换位，图案和编号保持正立。动画结束后才提交棋盘；恢复、切换主题或进入整图对照会取消未完成动作。取消后的旧动画或旧图片请求不能覆盖新状态。减少动态效果设置使用简短淡化换位。

打乱由一串真实合法旋转生成。撤销只作用于已提交的试转；打乱后重新计算试转次数。完整原画模式隐藏格缝、编号和旋钮，以便对照构图。

## 重新打包

在 `fourfold/` 执行：

```sh
node tools/build-board-previews.mjs
```

需要Node.js，以及支持AVIF的Pillow。脚本优先使用 `CODEX_PRIMARY_RUNTIME_PYTHON`，未设置时使用 `python3`。不需要安装前端打包依赖。

构建器读取实际模块源码，将本页需要的旋转规则按严格边界抽取，避免内嵌无关每日题库。若模块依赖或规则边界变化，构建会明确失败，要求复核。生产PNG和WebP均只读；AVIF仅用于消息内预览，编码前后校验尺寸相同。

默认生成项目内离线模板、`preview-build-report.json` 和 `/workspace/fourfold-live-board.html`。可以用 `--fragment /绝对路径/preview.html` 改变片段位置。消息内片段严格限制在980,000字节以内；报告记录实际编码质量、尺寸、原稿SHA256和文件体积。

## 验证边界

本轮通过资源与取图5项检查、交互控制器7项检查，以及共享轨迹5项检查。离线HTML和消息内片段分别执行了最终打包脚本的DOM接口检查，覆盖七主题加载、顺逆换位、动画锁、撤销、切图取消、整图对照、数字开关、打乱和复原；消息内片段也通过渲染包装器的格式及体积检查。最终离线文件3,877,039字节，片段955,922字节，预览AVIF quality51。

规则、资源、事务取消与自包含脚本可以在本地自动验证。当前云端浏览器只允许HTTP/HTTPS，拒绝直接打开本地模板，因此本轮没有完成浏览器渲染实测；也不将这些检查视为Cocos Creator或微信真机验收。

本轮交付的是已接入的本地资源与可操作模板，未发布公开站点。
