# 借个影子 · 独立试玩

五关小原型，单独入口 `fourfold/shadow-preview/`。不接入正式主页，不修改原拼图或点亮星图试玩。独立存储键 `STARMAP_SHADOW_DEMO_V1` 只保存选关、完成记录与声音偏好。

## 规则

划动选中的星星，沿上下左右方向滑到边缘、月岩、影子或另一颗星前面才停。每次成功移动只在出发格留下一个不可移动的影子，沿途不留。被挡住的无效操作不产生影子、不计步。所有星星分别停在对应颜色的空位才通关；经过空位不算。未完成时已归位的星星仍可移动。

支持指针拖动 / 手机划动。桌面可点选星星后用方向键；键盘聚焦星星也会选中。拖动时预览整条滑行路径与最终停点。撤销同时恢复星星、影子和步数；重来、任意选关、提示、通关后下一关均可用。第二关包含动态方向引导，提示以当前局面搜索，走入死路会建议撤销。

关卡最短步数为 1、3、5、6、7。后两关有金、蓝两颗星。无需倒计时和精确手速。

## 代码与资源

纯规则代码位于 `../cocos/assets/scripts/ShadowCore.js`，为后续 Creator 3.8.8 接入保留，不依赖 DOM 或引擎。当前交付是浏览器原型，不是 Creator 导出包。复用已有星片 WebP、美术字和音乐/音效；星星、目标和影子是用于交互的 SVG 图标。所有新增文件独立于现有玩法。

## 验证

- `node --test fourfold/shadow-preview/core.test.mjs`：6 项通过，覆盖五关解法、原地留影、借影子刹车、阻挡与边界、颜色目标与滑过不算、死路和搜索上限。
- `node --check fourfold/shadow-preview/app.mjs`：通过。
- 浏览器：实际指针拖动首关通关；第二关 3 步借影通关；撤销同时收回影子；第五关双色星星 7 步通关。
- 320 × 568、390 × 720 嵌入视口检查普通画面和结算画面，均无页面溢出。
- 未运行 Creator 编辑器、微信开发工具或实体手机测试。
