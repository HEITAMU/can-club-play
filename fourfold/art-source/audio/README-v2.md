# 石质交互音效 v2

用于《四格诡局》0.8.25 的按钮与四格旋转。两条成品均由 `build-stone-audio-v2.py` 原创、确定性合成；没有使用第三方样本、实地录音或在线生成结果。v1 原稿、脚本和记录保留。

## 设计与接入

| 素材 | 实际解码时长 | 结构 |
| --- | --- | --- |
| `ui-stone-press-v2` | 0.28 秒 | 短石面接触、极短按压摩擦、收束尾声；增加中频触感细节 |
| `stone-turn-v2` | 1.20 秒 | 起动接触、随速度起伏的不规则颗粒摩擦、1.064 秒起的单次落位 |

声音通过噪声激励非谐波、低 Q 共鸣带制作，摩擦采用数个频带与不规则压力、细颗粒叠加。输出清理直流和低频、限制高频、软控制瞬态并校准峰值；不依靠长低频轰响表现重量。音色是否适合具体手机仍需设备试听，不能仅凭频谱或测试判定。

母版为 48 kHz 单声道 24-bit WAV，运行文件为 192 kbit/s MP3。网页与 Cocos 的 MP3 字节一致，具体峰值、RMS、样本数和 SHA-256 见 `manifest-v2.json`。解码长度分别为 13440 和 57600 帧，MP3 容器含编码延迟时不以容器显示长度作为动作对齐依据。

网页 `audio.mjs` 与 Cocos `AUDIO_PATHS` 使用新文件名，防止旧缓存继续播放 v1。播放音量及取消、后台、静音、减少动态效果的行为沿用原实现。

本版还修复音频偶发加载失败后无法恢复：网页移除失败的下载／解码缓存，下一个有效手势可重试；原生缺少素材时由有效操作非阻塞触发缺失素材加载。加载恢复只供新操作使用，不补播错过的点击和已取消的动作。

## 复现

```bash
python3 fourfold/art-source/audio/build-stone-audio-v2.py
```

脚本需要 Python、NumPy、SciPy 和 ffmpeg/libmp3lame，复用 v1 的编码与一致性检查函数。固定种子为按钮 482501、转动 482502。

已检查真实编码／重新解码、时长、无削波、首尾边界及两端字节一致性；播放器生产方法测试覆盖有效触发、静音／取消、前后台、加载失败重试及不补播。这些检查不代替 Creator 引擎或手机听感验收。

本轮在线拟音请求在提交前被服务的余额条件阻止，实际提交数为 0；此处全部成品来自本地脚本。
