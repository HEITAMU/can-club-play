# 石质交互音效 v1

这两段音频供《四格诡局》的按钮点击与四格旋转使用。最终资源由本目录的确定性脚本原创合成，没有使用第三方录音、音乐、声音样本或已生成的模型音频，也不将其描述为实地录制的石板声。

## 素材

| 文件 | 解码时长 | 用途 |
| --- | --- | --- |
| `ui-stone-press-v1.wav` / `.mp3` | 0.28 秒 | 一个短、偏暖、收束迅速的石质按压反馈 |
| `stone-turn-v1.wav` / `.mp3` | 1.20 秒 | 接触起动、持续颗粒摩擦、减速与短促落位 |

WAV 为 48 kHz、单声道、24-bit PCM 母版。运行 MP3 为 48 kHz、单声道、192 kbit/s，网页与 Cocos 两份文件逐字节一致：

- 网页：`../../assets/audio/`
- 原生：`../../cocos/assets/resources/audio/`

按钮母版峰值目标 -7 dBFS，旋转母版峰值目标 -5 dBFS。具体的 MP3 解码峰值、RMS、样本数和 SHA-256 见 `manifest.json`。它们是素材本身的电平；游戏内播放音量由运行代码控制。

## 声音构成与时间线

接触声采用短促宽带噪声激励多个低 Q、非谐波共鸣带，避免电子蜂鸣或长铃声。摩擦声组合低中频拖动、石面颗粒与细小随机卡滞，不使用稳定的纯音振荡器。输出经过低频/DC 清理、温和高频衰减、软饱和、峰值校准和边界淡入淡出。

旋转对应游戏的 120 ms 聚焦、960 ms 移动、120 ms 落位：

- 约 12 ms：轻接触起动。
- 约 120–1080 ms：摩擦随移动速度增强再减弱，包含不规则细颗粒。
- 约 1067 ms 起：低沉落位和极短细屑尾声，至 1200 ms 完全结束。

只在有效旋转开始时播放一次完整旋转素材；旋钮不再叠加普通按钮声。取消动作、回主页、重开、静音或进入后台时应停止当前声源。减少动态效果模式应使用与其短动作相配的按钮触感，不把整段 1.2 秒素材强行升调压成短音。

## 可复现构建

在安装 Python 3、NumPy、SciPy、ffmpeg/libmp3lame 的环境中运行：

```bash
python3 fourfold/art-source/audio/build-stone-audio.py
```

本次构建使用 NumPy 2.3.5、SciPy 1.17.0。固定随机种子分别为 480187、480188。脚本会生成两份 WAV 母版、网页 MP3、相同的原生 MP3，并更新校验清单。

脚本检查两端内容相同、MP3 解码样本数准确、波形有限、没有削波，以及首尾边界已淡出。MP3 容器报告的时长可能包含编码器延迟与填充；应以带 gapless 元数据的实际解码样本数为准，旋转文件为 57600 / 48000 = 1.2 秒。

## 验证边界

已做编码与解码、样本时长、峰值、边界和两端一致性检查。这些数值检查不等于扬声器或耳机试听，也不证明所有设备的音色相同。素材的听感仍可在实际试玩中调整。

曾准备两条在线拟音请求，但服务在提交前因余额条件拒绝，实际任务提交数为 0；本目录的最终素材完全来自上述本地脚本，没有把未生成的拟音当作成品。
