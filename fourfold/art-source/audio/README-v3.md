# 短触感音效 v3

这版将《四格诡局》的音效拆成两个独立触点：按下旋钮时的一次短按压、拼图真正转完时的一次落座。普通按钮可复用按压声。两段均为本目录脚本生成的原创、确定性程序拟音，没有使用第三方录音、样本或模型生成音频；不描述为实录石板声。v1、v2 的素材与构建脚本全部保留。

## 文件与电平

| 素材 | MP3 解码时长 | 解码峰值 | 整段 RMS | 前 130 ms RMS | 用途 |
| --- | --- | --- | --- | --- | --- |
| `ui-stone-press-v3` | 0.240 秒 | −3.764 dBFS | −19.127 dBFS | −16.466 dBFS | 普通按钮 / 旋钮按下 |
| `stone-seat-v3` | 0.320 秒 | −3.767 dBFS | −19.569 dBFS | −15.670 dBFS | 拼图旋转完成后落位 |

母版为 48 kHz、单声道、24-bit PCM WAV，位于本目录；运行文件为 48 kHz、单声道、192 kbit/s MP3，位于 `../../assets/audio/`，并逐字节复制到 `../../cocos/assets/resources/audio/`。素材母版峰值目标 −3.5 dBFS，MP3 编码后峰值略有变化。游戏播放增益与声音开关由运行代码决定。

## 与 v2 的区别

接触体重新合成，采用短压力平台和随后的指数衰减，激励多个低 Q、非谐波的宽共鸣带；不再依赖只有几毫秒的激励峰。按压包含一层柔化接触头、清楚的中频主体，以及紧密、较轻的二次回弹。落位声增加低中频接触体，并在 76、94、122 ms 放入三颗很轻的离散颗粒。没有持续滑擦声、稳定纯音、长金属振铃、混响或音乐层。

按压声在 47 ms 加入轻回弹，落位声在 40 ms 加入较低的补充接触。它们属于单个短声音内部的微小结构；游戏中两次明确反馈仍分别由“按下”和“旋转完成”两个事件触发。音频开头保留约 10 ms 编码缓冲，防止强瞬态的 MP3 前回声贴到文件边界。

| 解码能量分布 | 按压声 | 落位声 |
| --- | --- | --- |
| 0–30 ms | 55.469% | 44.405% |
| 30–70 ms | 39.133% | 45.417% |
| 70–130 ms | 5.359% | 9.877% |
| 130–200 ms | 0.039% | 0.301% |
| 达到累计 95% 能量 | 71.479 ms | 83.771 ms |
| 达到累计 99% 能量 | 94.042 ms | 110.771 ms |

按压与落位的 300–3500 Hz 整段 RMS 分别为 −19.480 / −20.308 dBFS；低于 300 Hz 的能量占比分别约 5.693% / 14.566%。这让两者都有足够中频，同时让落位的频谱更厚。中频指标是素材特征，不是实际手机响度保证。

## 可复现构建与检查

```bash
python3 fourfold/art-source/audio/build-tactile-audio-v3.py
```

依赖 Python 3、NumPy、SciPy 和带 libmp3lame 的 ffmpeg。固定随机种子为 482601、482602。脚本复用 v1 的编码与双端复制函数，不修改旧版文件。详细峰值、RMS、能量时间、SHA-256 和文件路径见 `manifest-v3.json`。

构建检查 MP3 解码样本数、有限数值、首尾边界、采样峰值、4 倍过采样估计峰值及网页 / Cocos 字节一致性。两条文件解码首个 1 ms 峰值分别约 0.00000125 / 0.00000089，末个 1 ms 均为零。4 倍过采样估计峰值分别为 −3.737 / −3.750 dBFS，有充分削波余量。解码长度为 11520 / 15360 样本；MP3 容器时长包含编码填充，不能用它判断游戏时序。

这些检查只验证文件与数值，不等于扬声器、耳机或真机试听。未进行主观试听，也没有声称所有浏览器和设备上已经听感验收；最终音色和播放增益仍应结合实际试玩判断。
